# inventory-management

商品の入庫・在庫管理・出荷・出荷履歴・キャンセルを一元管理するシステムの **モック**。
業務フローと画面を確認するためのもので、HTML / CSS / 素の JavaScript のみで作られている。

## 起動方法

`src/index.html` をブラウザで開くだけで動作する（ビルド・インストール不要、オフライン対応）。

```
open src/index.html
```

`file://` でうまく動かない環境では、ローカルサーバー経由で開く。

```
python3 -m http.server 8000 --directory src
# → http://localhost:8000/
```

**製造番号のバーコード読み取り（カメラ）を使う場合は、`http://localhost` のようなセキュアなコンテキストで開く必要がある。**
`file://` やカメラ非対応ブラウザ、カメラ権限を拒否した場合はカメラを使えないため、手入力にフォールバックする。

## できること

| 画面 | 内容 |
| --- | --- |
| 在庫一覧 | 型名・図番・製造番号・案件番号・入荷月で検索。「明細」と「型名まとめ（在庫数の集計）」を切替 |
| 入庫 | 商品管理で登録済みの型名をプルダウンで選択（寸法・図番は自動表示）。製造番号・入荷月・案件番号を入力して在庫に登録。製造番号はカメラでのバーコード読み取りにも対応。コピー登録と連続登録モードで連番の商品に対応 |
| 出荷 | 在庫から選んだ商品を出荷。出荷した人・出荷先・案件番号が揃うまで出荷ボタンは押せない（宛先は任意） |
| 出荷履歴 | 出荷実績の一覧。出荷済みの商品はキャンセルして在庫に戻せる（履歴は残る） |
| 商品管理 | 商品マスタ（型名・寸法・図番）の登録・編集・削除。在庫・出荷履歴で使用中の商品は削除できない |

ログイン機能はない。出荷時に担当者名を入力して記録する。

## データについて

- データはブラウザの **localStorage** にのみ保存される（サーバー・DBなし）。
- 端末・ブラウザごとに独立していて、他の人とは共有されない。
- 初回起動時にデモデータが入る。画面下部の「デモデータを初期状態に戻す」でいつでも初期化できる。

## 今回のスコープ外

- **型名・寸法・図番のQRコード・写真読み取り** — 設計・実装していない。商品マスタの登録は手入力で行う。
  （製造番号のバーコード読み取りは実装済み。読み取った値は確認・修正してから登録する。）
- ログイン・権限管理 — 要件どおり設けていない。
- サーバー / DB / API — モックのため localStorage のみ。
