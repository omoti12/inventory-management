# 在庫管理システム

商品の入庫、在庫確認、出庫、出庫履歴の確認を行う社内向けアプリです。
データはMicrosoft 365のSharePointに保存され、サインインしたメンバー間で共有されます。

## 使う（本番）

以下のURLを開き、Microsoft 365アカウントでサインインしてください。

**https://omoti12.github.io/inventory-management/src/index.html**

インターネットに繋がっていれば、社内・社外を問わずどこからでもアクセスできます
（同じWi-Fiに繋いでいる必要はありません）。

## ローカルで動かす（開発・動作確認用）

コードを変更したときの動作確認用です。特別な準備やインストールは不要で、ターミナルで
このリポジトリのフォルダを開いてから次を実行してください。

```sh
./scripts/start.sh
```

表示された案内に従い、ブラウザで [http://localhost:8000](http://localhost:8000) を開きます。
サインインまでは確認できますが、実際のデータの読み書きは本番URL（上記）で確認してください
（Entra IDのリダイレクト先が本番URLに固定されているため）。終了するときは、スクリプトを実行した
ターミナルで `Ctrl + C` を押してください。

### うまく起動できないとき

- `Permission denied` と表示される場合は、最初の一度だけ `chmod +x scripts/start.sh` を実行してください。
- `Python 3 が見つかりません` と表示される場合は、Python 3 をインストールしてから再実行してください。
- 8000番ポートを別のアプリが使っている場合は、別の番号を指定できます。例: `./scripts/start.sh 8080`。その場合は [http://localhost:8080](http://localhost:8080) を開きます。

バーコード読み取り（在庫一覧の商品コード検索、フィルター入庫の製造番号）でカメラを使うには、ブラウザのカメラ利用を許可してください。カメラを使えない場合でも手入力できます。
なお、カメラは `https`、または `http://localhost` でしか使えません。スマートフォンからパソコンのIPアドレスへ `http://` でアクセスする構成では、ブラウザの仕様上カメラを利用できません
（本番URLは常時HTTPS配信のため、スマートフォンからでも問題なくカメラを使えます）。
ローカルでスマートフォン実機のカメラを試したい場合は `scripts/start.sh` の代わりに `scripts/start-https.sh` を使ってください。

## できること

サインインすると、まず「在庫一覧」が表示されます。

| 画面 | 内容 |
| --- | --- |
| 在庫一覧 | 商品コード（バーコード読み取り対応）・製品名・入荷日で検索。「明細」と「商品まとめ（在庫数量の集計）」を切替 |
| 入庫 | 商品コード・製品名は候補から選ぶか直接入力（未登録なら自動で商品マスタに追加）。数量・入庫した人（必須）、入荷日・備考（任意）を入力して在庫に登録。コピー登録で内容を引き継いだ再登録に対応 |
| 出庫 | 在庫から出庫する商品を選択。数量を指定した部分出庫（バッチ分割）にも対応。出庫した人・受注先・エンドユーザーが揃うまで出庫ボタンは押せない。複数人がほぼ同時に同じ在庫を出庫しようとした場合は、片方だけが成功し、もう片方には別の担当者が既に出庫済みである旨を知らせる |
| 出庫履歴 | 出庫実績の一覧。出庫済みの商品はキャンセルして在庫に戻せる（履歴は残る） |
| 商品管理 | 商品マスタ（商品コード・製品名）の登録・編集・削除、CSVファイルからの一括登録。在庫・出庫履歴で使用中の商品も、警告の上で削除できる |
| フィルター入庫／フィルター出庫／フィルター出庫履歴／フィルター商品管理 | 通常品とは別枠のフィルター品向けに、同じ業務フローを別画面で用意。フィルター入庫は製造番号・入荷日付の入力とバーコード読み取りに対応 |

Microsoft 365アカウントでのサインインが必須です（サインインすれば誰でも全操作が可能で、閲覧・編集などの細かい権限分けはありません）。
それとは別に、入庫時・出庫時にはそれぞれ担当者名を自由入力で記録します。

## データについて

- データは **Microsoft 365のSharePointリスト**（商品マスタ・在庫・出庫履歴）に保存され、Microsoft Graph API経由で読み書きする。
- 同じテナントにサインインしたメンバー全員で共有される（端末やブラウザに依存しない）。
- 複数人がほぼ同時に同じ在庫を出庫しようとした場合の排他制御あり（詳細は [docs/design.md](docs/design.md)）。

## このシステムで扱わないこと

- **商品コード・製品名のQRコード・写真読み取り** — 設計・実装していない。商品マスタの登録は手入力、入庫画面での自由入力、またはCSVからの一括登録で行う。
  （フィルター入庫の製造番号バーコード読み取りは実装済み。読み取った値は確認・修正してから登録する。）
- **アカウントごとの権限管理**（閲覧のみ／編集可などの細かい制御） — サインインすれば誰でも全操作が可能。
