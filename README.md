# 在庫管理システム（モック）

商品の入庫、在庫確認、出庫、出庫履歴の確認を、ブラウザだけで試せるサンプルアプリです。
データはこのパソコンのブラウザ内にだけ保存され、他の人やサーバーには送信されません。

## まずは起動する

特別な準備やインストールは不要です。ターミナルで、このリポジトリのフォルダを開いてから次を実行してください。

```sh
./scripts/start.sh
```

表示された案内に従い、ブラウザで [http://localhost:8000](http://localhost:8000) を開きます。
画面が表示されたら起動完了です。終了するときは、スクリプトを実行したターミナルで `Ctrl + C` を押してください。

### うまく起動できないとき

- `Permission denied` と表示される場合は、最初の一度だけ `chmod +x scripts/start.sh` を実行してください。
- `Python 3 が見つかりません` と表示される場合は、Python 3 をインストールしてから再実行してください。
- 8000番ポートを別のアプリが使っている場合は、別の番号を指定できます。例: `./scripts/start.sh 8080`。その場合は [http://localhost:8080](http://localhost:8080) を開きます。

バーコード読み取り（在庫一覧の商品コード検索、フィルター入庫の製造番号）でカメラを使うには、ブラウザのカメラ利用を許可してください。カメラを使えない場合でも手入力できます。
なお、カメラは `https`、または `http://localhost` でしか使えません。スマートフォンからパソコンのIPアドレスへ `http://` でアクセスする構成では、ブラウザの仕様上カメラを利用できません。

## できること

起動すると、まず「在庫一覧」が表示されます。

| 画面 | 内容 |
| --- | --- |
| 在庫一覧 | 商品コード（バーコード読み取り対応）・製品名・入荷日で検索。「明細」と「商品まとめ（在庫数量の集計）」を切替 |
| 入庫 | 商品コード・製品名は候補から選ぶか直接入力（未登録なら自動で商品マスタに追加）。数量・入庫した人（必須）、入荷日・備考（任意）を入力して在庫に登録。コピー登録で内容を引き継いだ再登録に対応 |
| 出庫 | 在庫から選んだ商品（ロット単位）を出庫。出庫した人・受注先・エンドユーザーが揃うまで出庫ボタンは押せない |
| 出庫履歴 | 出庫実績の一覧。出庫済みの商品はキャンセルして在庫に戻せる（履歴は残る） |
| 商品管理 | 商品マスタ（商品コード・製品名）の登録・編集・削除。在庫・出庫履歴で使用中の商品は削除できない |
| フィルター入庫／フィルター出庫／フィルター出庫履歴／フィルター商品管理 | 通常品とは別枠のフィルター品向けに、同じ業務フローを別画面で用意。フィルター入庫は製造番号・入荷日付の入力とバーコード読み取りに対応 |

ログイン機能はありません。入庫時・出庫時にはそれぞれ担当者名を入力して記録します。

## データについて

- データはブラウザの **localStorage** にのみ保存される（サーバー・DBなし）。
- 端末・ブラウザごとに独立していて、他の人とは共有されない。
- 初回起動時にはデモデータが入ります。画面下部の「デモデータを初期状態に戻す」でいつでも初期化できます。

> 注意: ブラウザのサイトデータを削除すると、このアプリに登録したデータも消えます。

## このモックで扱わないこと

- **商品コード・製品名のQRコード・写真読み取り** — 設計・実装していない。商品マスタの登録は手入力（または入庫画面での自由入力）で行う。
  （フィルター入庫の製造番号バーコード読み取りは実装済み。読み取った値は確認・修正してから登録する。）
- ログイン・権限管理 — 要件どおり設けていない。
- サーバー / DB / API — モックのため localStorage のみ。
- 出庫時の部分数量出庫 — 1回の出庫は選んだロットを丸ごと出庫する。
