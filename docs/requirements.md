# 在庫管理システム 要件定義

最終更新: 2026-08-07

このドキュメントは「何を作るか」を定める。作り方（データモデル・モジュール構成）は
[design.md](design.md)、動かし方は [../README.md](../README.md) を参照。

## 1. システム概要

商品マスタの管理と、商品の入庫・在庫管理・出荷・出荷履歴・キャンセルを一元管理するシステム。

- 商品は「商品名」ではなく **型名・寸法・図番** で管理する。
- 現物の1個ずつを **製造番号** で識別し、1個体＝在庫1個として扱う。
- 出荷時に必要な情報が揃っていなければ、出荷処理を完了できない。
- ログイン機能は設けず、出荷時に担当者名を入力して記録する。
- 画面は **在庫一覧 / 入庫 / 出荷 / 出荷履歴 / 商品管理** の5タブで構成する。

### 重要な必須要件

1. 商品情報は「商品名」ではなく **型名・寸法・図番**（商品マスタ）＋ **製造番号**（個体）で管理する
2. 出荷時に **出荷した人・出荷先・案件番号** の入力を必須とする（宛先は任意）
3. 必須項目が未入力の場合、出荷処理を実行できない
4. ログイン機能は設けず、担当者名を入力して記録する

### スコープ外

- **型名・寸法・図番をQRコード・写真から自動取得すること**。商品マスタの登録は手入力で行う。
  将来的に追加する場合は、QRに格納する項目とフォーマットを実物で確認したうえで設計する。
  （製造番号のバーコード読み取りは対象内。「4. 入庫」を参照）
- **ログイン・権限管理**（「8. 担当者の記録」の方針による）
- **サーバー / DB / API**。データはブラウザ内にのみ保存する。

## 2. 用語とデータの単位

| 用語 | 意味 |
| --- | --- |
| 商品マスタ | 型名・寸法・図番の組。**型名は一意**で、型名が決まれば寸法・図番も一意に定まる |
| 個体 | 入庫した現物1個。商品マスタを参照し、製造番号・入荷月・案件番号を個体ごとに持つ |
| 在庫 | 出荷されていない個体。1個体＝在庫1個 |
| 出荷 | 個体を出荷した実績。1件ごとに履歴として残る |

型名・寸法・図番は個体側では保持せず商品マスタを参照するため、
**商品マスタを編集すると在庫一覧・出荷履歴の表示にも即座に反映される**。

商品マスタを導入する前の形式で保存されたデータは、起動時に自動で商品マスタへ移行する。
利用者が意識する操作は不要（移行の詳細は [design.md](design.md) を参照）。

## 3. 商品管理（商品マスタ）

「商品管理」画面で商品マスタの **登録・編集・削除** を行う。ここで登録した商品が入庫時の選択肢になる。

| 項目 | 必須 | 内容 |
| --- | :---: | --- |
| 型名 | ○ | 商品の型名。**一意**で、既に登録済みの型名は重複登録できない |
| 寸法 | ○ | 商品の寸法 |
| 図番 | ○ | 図面番号 |

一覧には 型名・寸法・図番・在庫数・出荷済み数・操作（編集/削除）を表示する。

### 削除ポリシー

在庫にも出荷履歴にも使われていない（その商品を参照する個体が0件の）商品だけ削除できる。
使用中は削除ボタンを無効化し、「在庫 N 個・出荷済み M 個で使われているため削除できません」という理由をその場で示す。

## 4. 入庫

商品が入荷した際に、商品マスタから型名を選んで個体を在庫に登録する。

| 項目 | 必須 | 内容 |
| --- | :---: | --- |
| 型名 | ○ | 商品管理で登録済みの商品からプルダウンで選択 |
| 寸法 | - | 選択した型名に応じて自動表示（読み取り専用、編集不可） |
| 図番 | - | 選択した型名に応じて自動表示（読み取り専用、編集不可） |
| 製造番号 | ○ | 商品固有の製造番号 |
| 入荷月 | ○ | 商品が入荷した年月（YYYY-MM） |
| 案件番号 | ○ | 商品に紐づく案件番号 |

- 製造番号が在庫中の商品と重複する場合は登録できない。
- 商品が1件も登録されていない場合、警告と「商品管理へ」の導線を表示し、登録ボタンを無効化する。

### 製造番号のバーコード読み取り

製造番号は現物にバーコードで印字されているため、製造番号欄からカメラで読み取って入力できる。

- ブラウザの `BarcodeDetector` API と `getUserMedia` を使い、カメラ映像からバーコードを読み取る。
- 対応形式は `BarcodeDetector.getSupportedFormats()` で実際に使えるものに絞り込む
  （Code 128 / Code 39 / EAN-13 / EAN-8 / ITF / Codabar / UPC-A / UPC-E / QR）。
- 読み取りに成功するとカメラを停止してモーダルを閉じ、製造番号欄にフォーカスを戻す。
- 読み取った値は製造番号欄に入るだけで、**利用者が確認・修正してから登録する**（読み取り即登録ではない）。
- 非対応ブラウザ・カメラ権限拒否・`file://` で開いた場合はカメラを使えないため、
  その旨を案内したうえで手入力にフォールバックする。
- カメラを使うには `http://localhost` などの**セキュアなコンテキスト**で開く必要がある。

### 製造番号のコピー登録

製造番号は個体ごとに異なるため、単純な一括登録では対応しにくい。
そこで、既存の個体をコピーし、製造番号など必要な項目だけ変更して登録する。

- 在庫一覧の「コピー」から、型名・入荷月・案件番号を引き継ぐ（寸法・図番は型名から自動表示される）。
- 製造番号は末尾の数字を1つ進めた候補を自動で入れる（桁数は維持：`0001` → `0002`、`S-003` → `S-004`）。
- 「連続登録モード」を有効にすると、登録後も入力内容を残したまま製造番号だけ次の連番に進み、
  連番の商品を続けて登録できる。

## 5. 在庫一覧と検索

出荷されていない商品を一覧表示する。表示は2通りを切り替えられる。

- **明細表示**：製造番号ごとに1行。型名・寸法・図番・製造番号・入荷月・案件番号。
- **型名まとめ表示**：商品（型名＋寸法＋図番）ごとにまとめ、**現在の個数** を集計表示。

商品が出荷されると在庫一覧から表示されなくなる。

### 検索条件

以下の条件で検索でき、互いに組み合わせられる。

| 条件 | 一致方法 |
| --- | --- |
| 型名 | 部分一致 |
| 図番 | 部分一致 |
| 製造番号 | 部分一致 |
| 案件番号 | 部分一致 |
| 入荷月 | 完全一致 |

**型名を検索して現在の在庫数を確認できること**を重要な機能とする。

> 例：型名「ABC-100」で検索 → 現在庫：10 個

## 6. 出荷

在庫一覧から出荷する商品を選択（複数可）し、出荷処理を行う。

| 項目 | 必須 | 内容 |
| --- | :---: | --- |
| 出荷した人 | ○ | 実際に出荷作業を行った人の名前（例：丸山） |
| 出荷先 | ○ | 商品を出荷する場所・会社（例：株式会社○○ 東京営業所） |
| 宛先 | | どこの誰宛か（例：営業部　○○様）。任意入力 |
| 案件番号 | ○ | 対象となる案件番号 |

出荷先を必須にすることで、履歴から「どこに・誰が出荷したのか」を必ず確認できるようにする。
宛先が入力されていれば「誰宛に」も確認できる。

### 処理の流れ

商品を選択 → 出荷情報を入力 → 必須項目を確認
→ すべて入力済みなら出荷可能／未入力があれば出荷不可
→ 「出荷」ボタン → 在庫一覧から消える → 出荷履歴へ登録

**必須項目に未入力が1つでもある間は出荷ボタンを押せない。** 未入力の項目名は画面上に表示する。

## 7. 出荷履歴とキャンセル

出荷した商品を履歴として保存する。出荷日時の新しい順に表示し、状態とキーワードで絞り込める。

| 項目 | 内容 |
| --- | --- |
| 型名 / 寸法 / 図番 / 製造番号 / 入荷月 | 出荷した商品の情報（型名・寸法・図番は商品マスタから引く） |
| 案件番号 | 出荷時に入力した案件番号 |
| 出荷した人 | 出荷担当者 |
| 出荷先 | 出荷先 |
| 宛先 | 誰宛か |
| 出荷日時 | 出荷した日時 |
| 状態 | 出荷済み／キャンセル |

### キャンセル

出荷履歴から出荷済みの商品をキャンセルできる。

対象を選択 → 「キャンセル」ボタン → 確認 → 実行 → 在庫へ戻す

- キャンセルした商品は再度在庫一覧に表示される。
- 履歴自体は削除せず、状態を「キャンセル」に変更して残す。
- キャンセル済みの出荷は再キャンセルできない。

## 8. 担当者の記録（ログイン機能を設けない）

ID・パスワードによるログインは設けず、出荷のたびに「出荷した人」の名前を入力して担当者を記録する。
ユーザーアカウントの管理を不要にして、システムを簡単に利用できるようにすることを狙いとする。

## 9. 案件番号の扱い

案件番号は入庫・出荷の両方に関わるため、扱いをここにまとめる。

- 入庫時・出荷時ともに必須。
- 出荷時に案件番号が未入力なら出荷ボタンを押せない。
- 案件番号での商品検索に対応する。
- 選択した商品の案件番号が1種類に定まる場合は、出荷画面で初期値として自動入力する。

## 10. 全体業務フロー

### 商品マスタ登録

商品管理画面 → 型名・寸法・図番を入力 → 登録 → 入庫画面のプルダウンに反映

### 入庫

商品到着 → 入庫画面で型名を選択（またはコピー登録）→ 製造番号・入荷月・案件番号を入力
（製造番号はバーコード読み取りも利用可）→ 登録 → 在庫一覧に表示

### 出荷

在庫一覧 → 商品検索 → 対象商品を選択 → 出荷した人・出荷先・宛先・案件番号を入力
→ 必須項目チェック → 出荷 → 在庫一覧から消える → 出荷履歴に保存

### キャンセル

出荷履歴 → 対象商品を選択 → キャンセル → 在庫へ戻る
