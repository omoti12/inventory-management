# 在庫管理システム 要件定義

最終更新: 2026-08-26

このドキュメントは「何を作るか」を定める。作り方（データモデル・モジュール構成）は
[design.md](design.md)、動かし方は [../README.md](../README.md) を参照。

## 1. システム概要

商品マスタの管理と、商品の入庫・在庫管理・出庫・出庫履歴・キャンセルを一元管理するシステム。
通常品とは別枠で扱う「フィルター品」向けに、同じ業務フローを別画面（フィルター入庫／フィルター出庫／
フィルター出庫履歴／フィルター商品管理）で用意する。

- 商品は「型名」ではなく **商品コード・製品名** で管理する。
- 入庫は現物1個ずつではなく、**数量** 単位のバッチ（ロット）として在庫に登録する（受注番号のような伝票番号は持たない）。
- 出庫時に必要な情報が揃っていなければ、出庫処理を完了できない。
- Microsoft 365アカウントでのサインインを必須とし、データはSharePointに保存して複数人で共有する
  （入庫時・出庫時の担当者名入力は別途、担当者の記録として行う。詳細は8章）。
- 起動時は、直前に開いていた画面を`localStorage`から復元して表示する（初回アクセス時や
  記録が無効な場合は**在庫一覧**タブを表示する）。出庫画面などを開いたままリロードしても
  同じ画面に戻れるようにするため。
- 在庫一覧では、カメラでバーコードを読み取って商品コードを検索できる。
- 画面は **在庫一覧 / 入庫 / 入庫履歴 / 出庫 / 出庫履歴 / 商品管理 / 出荷先マスタ** の通常7タブと、
  **フィルター在庫一覧 / フィルター入庫 / フィルター入庫履歴 / フィルター出庫 / フィルター出庫履歴 /
  フィルター商品管理** のフィルター用6タブ、計13タブで構成する（メインメニューは「通常」
  「フィルター」の2段に分けて表示する）。

### 重要な必須要件

1. 商品情報は「商品コード・製品名」（商品マスタ）で管理し、入庫は「数量」のバッチ単位で登録する
2. 入庫時に **商品コード・製品名・数量・入庫した人** の入力を必須とする（入荷日・備考は任意）
3. 出庫時に **備考以外のすべての項目**（出庫した人・出庫日・出荷先コード等・受注番号）の入力を必須とする
4. 必須項目が未入力の場合、入庫・出庫処理を実行できない
5. Microsoft 365アカウントでのサインインを必須とし、複数人が同じデータへ同時にアクセスできる
6. フィルター品は通常品と商品マスタ・在庫を分離し、専用画面で管理する
7. 在庫一覧の商品コード検索は、手入力のほかカメラでのバーコード読み取りにも対応する

### スコープ外

- **商品コード・製品名をQRコード・写真から自動取得すること**。商品マスタの登録は手入力（または入庫画面での自由入力）で行う。
- **アカウントごとの権限管理**（閲覧のみ／編集可などの細かい制御）。サインインすれば誰でも全操作が可能。
- **入庫時の受注番号・案件番号の入力**。伝票番号は扱わず、商品コード・数量・入庫した人などのみで管理する
  （フィルター入庫の製造番号は個体識別のため引き続き扱う）。

## 2. 用語とデータの単位

| 用語 | 意味 |
| --- | --- |
| 商品マスタ | 商品コード・製品名の組。**商品コードは一意**。通常品／フィルター品で別管理する |
| 在庫（通常品） | 入庫した1ロット。商品マスタを参照し、数量・入庫した人・入荷日（任意）・備考を持つ |
| 在庫（フィルター品） | 入庫した1個体。商品マスタを参照し、製造番号・入荷日付を持つ（フィルター入庫は現状の運用を維持） |
| 出庫 | 在庫（行単位、または数量指定によるバッチ分割）を出庫した実績。1件ごとに履歴として残る |

商品コード・製品名は在庫側では保持せず商品マスタを参照するため、
**商品マスタを編集すると在庫一覧・出庫履歴の表示にも即座に反映される**。

データは商品マスタ・在庫・出庫履歴のすべてがSharePointリストに保存され、Microsoft 365の
同じテナントにサインインしたメンバーであれば誰でも同じデータにアクセスできる
（保存先の詳細は [design.md](design.md) を参照）。

## 3. 商品管理（商品マスタ）

「商品管理」画面で通常品の商品マスタの **登録・編集・削除** を行う。ここで登録した商品コードが、
入庫画面の入力候補（検索付きプルダウン兼自由入力）になる。

| 項目 | 必須 | 内容 |
| --- | :---: | --- |
| 商品コード | ○ | 商品の識別コード。**一意**で、既に登録済みのコードは重複登録できない |
| 製品名 | ○ | 商品の名称 |
| 保管場所 | - | 「第一工場」「本社在庫」から選択（任意入力）。フィルター商品管理には無い項目 |

一覧には 商品コード・製品名・保管場所・在庫数・出庫済み数・操作（編集/削除）を表示する。
保管場所は、在庫一覧（明細表示）・出庫画面の在庫検索一覧・出庫履歴にも表示する。

### 削除ポリシー

在庫や出庫履歴で使われている商品も削除できる（誤って登録・使用してしまった商品を消せるようにするため）。
使用中の商品を削除しようとすると「在庫 N 個・出庫済み M 個で使われています。削除するとそれらの表示は
『(削除済み商品)』になります。それでも削除しますか？」と警告した上で確認を取る。

一覧の各行にチェックボックスがあり、複数選択して「選択した◯件を削除」でまとめて削除できる
（ヘッダーの「すべて選択」で一括選択も可能）。選択した中に使用中の商品が含まれる場合は、
1件ずつではなく選択全体の使用状況（使用中の件数・在庫と出庫済みの合計数）をまとめた
確認メッセージを1回だけ表示する。フィルター商品管理にも同じ一括削除がある。

### CSVからの一括登録

エクセルなどで管理している商品一覧をまとめて登録できる。CSVファイルを選んで「取り込む」を押すと、
1行目を見出し行として読み飛ばし、1列目を商品コード、2列目を製品名として1件ずつ登録する。
既に登録済みの商品コードはスキップし、結果（登録件数・スキップ件数・失敗件数とその商品コード）を
まとめて画面に表示する。文字コードはUTF-8・Shift_JIS（Windows版Excelの既定のCSV保存形式）の
どちらにも対応する。フィルター商品管理にも同じ機能がある。

### フィルター商品管理

通常の商品管理とは別に、フィルター品専用の商品マスタを「フィルター商品管理」画面で管理する。
項目・削除ポリシーは通常の商品管理と同じ（商品コード・製品名のみ、必須）。

## 4. 入庫

商品が入荷した際に、1ロット（数量）を在庫に登録する。

| 項目 | 必須 | 内容 |
| --- | :---: | --- |
| 商品コード | ○ | 商品管理に登録済みの候補から選ぶか、直接入力する（未登録のコードは自動で商品マスタに追加登録される） |
| 製品名 | ○ | 商品コードの候補選択時は自動補完されるが、手動で修正・入力できる |
| 数量 | ○ | 入庫した個数（0以上の整数。在庫がまだ無い状態でも入庫記録自体を先に登録できるよう、0も入力できる） |
| 入庫した人 | ○ | 実際に入庫作業を行った人の名前（例：丸山） |
| 入荷日 | - | 商品が入荷した日付。任意入力 |
| 備考 | - | 申し送り事項など。任意入力 |

### 商品コード・製品名の自由入力

- 商品コード欄・製品名欄は `<datalist>` による検索付き入力欄で、登録済み商品からの選択と自由入力の両方に対応する。
- 商品コードの入力欄からフォーカスが外れた時点で、既存商品と一致すれば製品名を自動補完する（上書き修正は可能）。
- 一致する商品コードが無い状態で登録すると、その場で新しい商品として商品マスタに自動登録される。

### コピー登録

在庫一覧の「コピー」から、商品コード・製品名・数量・入荷日・備考を入庫フォームに引き継ぎ、
値を確認・修正してから登録できる。

### 商品コード・製品名の相互自動入力

商品コードと製品名を同じ運用にしていることが多いため、どちらか一方を入力するともう一方が
自動で埋まる。商品コードを入力した場合は、登録済みの商品と一致すればその製品名を、
一致しなければ商品コードをそのまま製品名にコピーする。製品名を入力した場合は、その名前が
登録済みの商品と完全一致すれば商品コードが既に入力済みでもその商品の正しいコードに更新し
（別の登録済み商品に選び直した場合に追従するため）、一致しない新しい製品名で商品コードが
空の時だけ製品名をそのまま商品コードにコピーする。

### 入力途中で他の画面に移動した時

入力途中でも、入庫画面（フィルター入庫も同様）を離れて他の画面（在庫一覧・商品管理など）に
移動すると、入力内容は残さず消える。入庫画面はいろいろな画面と行き来しながら使うことが
多いため、途中で離れて戻ってきた時に古い入力が残っていて紛らわしいのを防ぐため。

### 入庫履歴

入庫した通常品を、在庫中・出庫済みを問わず一覧で確認できる。状態（すべて/在庫中/出庫済み）と
キーワードで絞り込め、「登録日時」列の見出しをクリックすると新しい順・古い順を切り替えられる
（出庫履歴の並べ替えと同じ仕組み）。

一覧の各行から「編集」を選ぶと、数量・入荷日・入庫した人・備考をその場で修正できる
（入庫時に個数を間違えた場合などに対応するため）。商品そのものの変更（別の商品コードへの
差し替えなど）はできない。

在庫中（まだ出庫されていない）の行だけ「削除」もできる（誤って登録してしまった記録を
片付けるため）。出庫済みの行は削除できない（出庫履歴側でそのキャンセル時に在庫を戻す先が
無くなってしまうため）。ただし、参照している商品自体が商品管理側で削除済みになっている
行（商品コードが「(削除済み商品)」と表示されている行）は、出庫済みでも削除できる
（商品が無くなっている以上、在庫を戻す心配がないため）。

削除できる行（在庫中、または商品削除済みの行）にはチェックボックスがあり、複数選択して
「選択した◯件を削除」でまとめて削除できる（ヘッダーの「すべて選択」も、削除できる行だけを
対象にする）。フィルター品にも同じ入庫履歴画面（フィルター入庫履歴）があり、一括削除も同様。

## 5. 在庫一覧と検索

出庫されていない通常品を一覧表示する（フィルター品は対象外。フィルター品はフィルター出庫画面で扱う）。
アプリ起動時は必ずこの画面を表示する。表示は2通りを切り替えられる。

- **明細表示**：ロットごとに1行。商品コード・製品名・数量・入荷日・備考。
- **商品まとめ表示**：商品（商品コード＋製品名）ごとにまとめ、**在庫数量の合計** を集計表示。

商品が出庫されると在庫一覧から表示されなくなる。

### 検索条件

以下の条件で検索でき、互いに組み合わせられる。

| 条件 | 一致方法 |
| --- | --- |
| 商品コード | 部分一致。カメラでバーコードを読み取って入力することもできる |
| 製品名 | 部分一致 |
| 入荷日 | 完全一致 |

**商品コードを検索して現在の在庫数量を確認できること**を重要な機能とする。

> 例：商品コード「ABC-100」で検索 → 現在庫：10 個

## 6. 出庫

在庫一覧から出庫する商品（複数行可）を選択し、出庫処理を行う。

| 項目 | 必須 | 内容 |
| --- | :---: | --- |
| 出庫した人 | ○ | 実際に出庫作業を行った人の名前（例：丸山）。過去に入力した名前がプルダウン候補として出るので、毎回入力し直さず選べる（候補に無い新しい名前もそのまま入力できる） |
| 出庫日 | ○ | 出庫した日付を選択する |
| 出荷先コード・小番、出荷先名1、受注番号1〜3 | ○ | 社内の会計/販売システムへのCSV連携用（詳細は[design.md](design.md)） |
| 出荷先名2 | - | 出荷先名2が無い出荷先もあるため任意入力 |
| 備考 | - | 任意入力 |

出荷先名2と備考以外はすべて必須項目にしている。フィルター出庫も同じ項目構成
（「9. フィルター品」を参照）。かつては受注先・エンドユーザーが必須項目だったが、
出荷先コード・名・受注番号に置き換わったため廃止した。

出荷先コード・小番は、あらかじめ「出荷先マスタ」画面（一覧の登録・編集・削除、CSVからの
一括登録に対応）に登録しておくと、出庫フォームで出荷先コードを入力した時点でその出荷先
小番・出荷先名1/2がまとめて自動入力される（コードに複数の小番が登録されている場合は
いったん一番小さい小番のものが入るので、違っていれば小番を直すと出荷先名がその小番の
登録内容に合わせ直される）。未登録の組み合わせは自由入力のまま出庫できる。一覧の各行に
チェックボックスがあり、複数選択して「選択した◯件を削除」でまとめて削除することもできる。

出荷先名からも自動入力できる（出荷先名を先に入力すると出荷先コード・小番・出荷先名2が
自動で埋まる）。間違った出荷先を選んでしまい出荷先名を消して選び直したい時は、出荷先名を
空にすると出荷先コード・小番・出荷先名2も一緒に空になる（消し忘れた古いコードのまま
出庫してしまう事故を防ぐため）。

### 処理の流れ

商品を選択 → 出庫情報を入力 → 必須項目を確認
→ すべて入力済みなら出庫可能／未入力があれば出庫不可
→ 「出庫する」ボタン → 在庫一覧から消える → 出庫履歴へ登録

**必須項目に未入力が1つでもある間は出庫ボタンを押せない。** 未入力の項目名は画面上に表示する。

在庫検索から商品ごとに出荷したい数量を指定して追加でき、指定数量が1バッチに満たない場合は
自動でバッチを分割し、端数は元のバッチとして在庫に残す（部分数量出庫）。

複数人がほぼ同時に同じ在庫を出庫しようとした場合、どちらか一方だけが成功し、
もう一方には「別の担当者が既に出庫済み」であることを案内し、二重に出庫記録が作られないようにする。

## 7. 出庫履歴とキャンセル

出庫した商品を履歴として保存する。初期表示は出庫日時の新しい順で、状態とキーワードで絞り込める。
「出庫日時」列の見出しをクリックすると、新しい順・古い順を切り替えられる。
「CSVダウンロード」で、今表示している絞り込み・並び順のままCSVファイルとして保存できる。

1回の出庫操作で複数の商品をまとめて出庫した場合、履歴は商品の数だけ別々の行にはならず、
「▶ 3件の商品をまとめて出庫」のような1つのまとめ行として表示される。クリックすると開閉し、
展開すると商品ごとの内訳を確認でき、内訳の各商品を個別にキャンセル・削除できる。まとめ行には
グループ内の出庫済みをまとめてキャンセル・キャンセル済みをまとめて削除するボタンもある。

### CSV出力する行の選択

まとめ行（1回の出庫操作）ごとにチェックボックスがあり、CSV出力する範囲を選べる。
- ヘッダーのチェックボックスで、今表示中の行をまとめて選択/解除できる。
- 「この月を選択」で、選んだ年月の出庫操作だけに選択を入れ替えられる（絞り込み条件に関係なく
  全期間から月で選ぶ）。
- 1件でも選択していればCSVはその分だけを出力し、何も選んでいなければ今まで通り表示中の
  全件を出力する。

### 編集

出庫した後に、出庫した人・出庫日・出荷先コード/小番・出荷先名1/2・受注番号1〜3・備考の
入力間違いに気づいても、「編集」ボタンから出庫をキャンセルせずにその場で直せる。何を出庫したか
（商品・数量）自体は編集できない（間違えた場合はキャンセルして出庫し直す）。

| 項目 | 内容 |
| --- | --- |
| 商品コード / 製品名 / 数量 / 入荷日 | 出庫した商品の情報（商品コード・製品名は商品マスタから引く） |
| 出庫した人 | 出庫担当者 |
| 受注先 | 出庫先 |
| エンドユーザー | 誰宛か |
| 出庫日時 | 出庫した日時 |
| 状態 | 出庫済み／キャンセル |

### キャンセル

出庫履歴から出庫済みの商品をキャンセルできる。

対象を選択 → 「キャンセル」ボタン → 確認 → 実行 → 在庫へ戻す

- キャンセルした商品は再度在庫一覧に表示される。
- 履歴自体は削除せず、状態を「キャンセル」に変更して残す。
- キャンセル済みの出庫は再キャンセルできない。
- キャンセル済みの履歴は、間違えて確定させた記録を片付けられるよう削除できる（元に戻せない）。
  出庫済みのままの履歴は、在庫の実数と食い違うため削除できない。

## 8. サインインと担当者の記録

Microsoft 365アカウントでのサインインを必須とし、サインインしたメンバーであれば誰でも
全操作を行える（アカウントごとの権限の細かい制御は行わない）。それとは別に、
入庫のたびに「入庫した人」、出庫のたびに「出庫した人」の名前を自由入力で記録する
（サインインアカウントの氏名を自動転記するのではなく、実際に作業した人を都度入力する運用）。

### データの更新

他の人が追加・変更した内容は、リロードしない限り自動では反映されない。画面右上の
「🔄 更新」ボタンを押すと、その時点の最新データを取り直して今見ている画面に反映する
（入力中のフォームには影響しない）。自動での定期更新は行わない。

## 9. フィルター品（別枠の商品ライン）

フィルター品は通常品と商品マスタ・在庫を分離し、以下の専用画面で同等の業務フローを扱う。

| 画面 | 内容 |
| --- | --- |
| フィルター商品管理 | フィルター品の商品マスタ（商品コード・製品名、必須）を登録・編集・削除（複数選択しての一括削除も可） |
| フィルター在庫一覧 | 在庫中のフィルター品を検索・一覧表示。通常の在庫一覧と同じ「商品まとめ」（商品単位で件数を表示）・「明細」（製造番号ごとの1行）の切替に対応 |
| フィルター入庫 | フィルター商品管理で登録した商品を選び、**製造番号**（必須）・入荷日付（任意）を入力して入庫。製造番号はバーコード読み取りに対応（「4. 入庫」の通常品とは異なり、個体単位＝製造番号での管理を維持する）。同じ製造番号のものが複数個まとめて入荷した場合のために「数量」欄（任意、省略時1）があり、指定した数だけ同じ内容の入庫記録をまとめて登録できる。製造番号の末尾が連番になっている場合向けに「製造番号の末尾を連番にして登録する」チェックボックスもあり、チェックすると数量分だけ製造番号の末尾を1ずつ増やしながら登録できる（例：62---100007を数量15で登録すると62---100007〜62---100021の15件） |
| フィルター入庫履歴 | 入庫したフィルター品を、在庫中・出庫済みを問わず一覧で確認。各行から製造番号・入荷日・備考を編集でき、在庫中の行、または参照商品が削除済みの行は削除もできる（入庫履歴と同じ考え方） |
| フィルター出庫 | 画面内の検索欄で商品コード・製品名・製造番号を絞り込み、出庫したい個数を指定して追加するか、フィルター在庫一覧から選んだ商品を出庫対象にし、出庫した人・出庫日・出荷先コード等・受注番号（備考以外は必須）を入力して出庫。通常の出庫と同じ項目構成 |
| フィルター出庫履歴 | フィルター品の出庫実績の一覧・キャンセル |

フィルター品は通常の在庫一覧・出庫・出庫履歴には表示されない。

## 10. 全体業務フロー

### 商品マスタ登録

商品管理画面 → 商品コード・製品名を入力 → 登録 → 入庫画面の候補に反映

### 出荷先マスタ登録（任意）

出荷先マスタ画面 → 出荷先コード・小番・出荷先名1/2を入力（またはCSVで一括登録）→ 登録
→ 出庫フォームで該当コード・小番を入力すると出荷先名1/2が自動入力される

### 入庫

商品到着 → 入庫画面で商品コード・製品名を選択または入力（またはコピー登録）
→ 数量・入庫した人・入荷日・備考を入力 → 登録 → 在庫一覧に表示

### 出庫

在庫一覧 → 商品検索 → 対象商品を選択 → 出庫した人・出庫日・出荷先コード等・受注番号を入力
→ 必須項目チェック → 出庫する → 在庫一覧から消える → 出庫履歴に保存

### キャンセル

出庫履歴 → 対象商品を選択 → キャンセル → 在庫へ戻る

### フィルター品

フィルター商品管理で商品を登録 → フィルター入庫で製造番号・入荷日付を入力して登録
→ フィルター出庫で対象を選び出庫 → フィルター出庫履歴で確認・キャンセル
